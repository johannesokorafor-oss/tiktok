# Rumble (optional) — PREPARE_ONLY (no official public VOD upload API)

| | |
|---|---|
| **Mode** | `PREPARE_ONLY` — the app never uploads to Rumble |
| **Reason** | *Rumble VOD upload API is not currently verified as an official public API. Manual upload is required.* |
| **Default** | `RUMBLE_ENABLED=false` |

## What Rumble officially publishes (checked 2026-09-27)

Rumble's documented developer surface is the **Live Stream API v1.1**
(<https://rumble.com/account/livestream-api>): a read-only JSON feed with
follower, subscriber, chat and rant data for stream overlays. That is a *live
stream data* API — it is **not** a VOD upload API and must not be confused with
one. No official, publicly documented endpoint for uploading a video file
exists; upload endpoints appear only as part of negotiated
enterprise/partner packages.

Accordingly this integration:

* makes **zero HTTP requests** (a test asserts the module does not even import
  an HTTP client),
* never uses browser automation, scraping, private or reverse-engineered
  endpoints,
* cannot be forced into upload mode: setting `RUMBLE_MODE=UPLOAD_PRIVATE` is
  ignored while no official API is verified (also test-enforced).

## What "Prepare for Rumble" produces

```
output/<job>/rumble_ready.mp4        the file to upload
output/<job>/rumble_metadata.txt     title, description, tags, channel, licence
                                     option and step-by-step upload instructions
output/<job>/rumble_metadata.json    machine-readable record (api_calls_made: 0)
```

Then: open <https://rumble.com/upload.php>, select the file, paste the metadata,
choose your channel/visibility/licensing and **pick your own thumbnail** —
none is generated by this application.

## Setup on Windows

```ini
RUMBLE_ENABLED=true
RUMBLE_MODE=PREPARE_ONLY
RUMBLE_CHANNEL=my-channel
RUMBLE_LICENSE_OPTION=Rumble Only
```

## If Rumble publishes an official upload API

Implement it as a separate adapter and flip `OFFICIAL_VOD_UPLOAD_API` in
`app/platforms/rumble.py`; `RUMBLE_MODE=UPLOAD_PRIVATE` then becomes effective.
Until then the honest answer stays: manual upload.
